# In Program.cs heb je startcode gekregen maar die is nog niet helemaal af

## Wat je moet doen om dit af te maken:

- Groepeer cases: Je kunt meerdere cases onder elkaar plaatsen zonder break als ze dezelfde uitkomst hebben (bijvoorbeeld case 12:, case 1:, case 2:).
- Voorzie een break: Zorg dat elke logische blok afsluit met het sleutelwoord break om foutmeldingen te voorkomen.
- Gebruik de default: De default vangt alle getallen op die buiten de reeks 1-12 vallen.
